# Student navigator — 25 November 2026

The approved L2 Probability and Statistics test moved from 29 November 2026, 16:30–17:10, to 1 December 2026 at the same time (Africa/Algiers). All 633 student records and room allocations are preserved. No other test was moved or added.

Name search uses a one-time normalized index, suggestions from the first letter, token-order matching and highlighted results. Registration lookup retains the existing hashed public lookup; original registration numbers and administrative records are not exported to this portal.

The approved map remains available. The optional, locally bundled Three.js scene loads only when guidance starts. Camera movement is a schematic simulation from the courtyard, not phone tracking or a measured building survey. WebGL is preferred; a lightweight Three.js SVG renderer and the approved 2D map provide fallbacks. No runtime CDN is required.

Checks: `node tools/test_exam_navigator.cjs`, `node tools/test_navigation_upgrade.cjs`, `python tools/test_reschedule.py`. Full before/after comparisons also confirmed that the private register and invigilation changes preserve student lists, room assignments and all 11 teachers associated with the moved period. Private reports stay outside this repository.

Browser QA covered first-letter suggestions, exact registration lookup, student details, the December announcement, Arabic/English, lightweight 3D camera guidance, pause, step navigation, overview and the approved-map fallback. Hardware WebGL and physical-phone performance were not measured in the cloud browser. The UI adapts to small screens and reduced-motion settings.

Calendar exports preserve the moved event UID and increment its sequence. Previously imported phone calendars are outside the website's control; users should reimport the updated calendar and check for an old duplicate. In-page reminders use the updated schedule while the page is open.

Rebuild the 3D bundle with `npm ci && npm run build` from `tools/navigation-3d`. Dependencies are pinned and the Three.js license is included.
